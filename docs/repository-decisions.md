# Repository Decisions

## Name

Default repository name: `doujin-treasure-map`.

It is explicit, easy to remember, and does not bind the app to one specific event. Alternative names considered:

- `event-treasure-route`
- `circle-check-map`
- `my-doujin-route`

`doujin-treasure-map` remains the best initial choice because it describes the product concept directly.

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Supabase Auth
- Vercel

Supabase packages are not installed yet because Phase 1 should create/connect the actual Supabase project first.
